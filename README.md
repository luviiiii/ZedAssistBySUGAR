# ZedAssistBySUGAR

Chrome extension that helps a ZED assessor with the Bronze desktop assessment: it reads the case, checks documents and photos with a Google AI key (your own, free), fills each clause and stops before Final Submit. **It never presses Final Submit - you do.**

## Install (1 minute)
1. Download **ZedAssistBySUGAR.zip** from the latest [Release](../../releases/latest) and unzip it somewhere permanent.
2. Chrome > `chrome://extensions` > turn on **Developer mode** > **Load unpacked** > choose the folder that contains `manifest.json`.
3. Pin the extension, open the assessor portal, click the icon and follow the 3 steps.

## Update
When a new release is published, a banner appears in the extension. Download the new zip, unzip over the old folder, press the reload arrow on `chrome://extensions`.
